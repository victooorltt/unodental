# UNO DENTAL — Rediseño Web

Rediseño moderno, limpio y elegante para la clínica dental **UNO DENTAL** (Valladolid).

## 🚀 Tecnologías

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Iconos:** [Lucide React](https://lucide.dev/)
- **Tipografía:** Inter (`next/font/google`)
- **Imágenes:** Formato WebP optimizado

## 📄 Páginas

- **Inicio (`/`)**: Hero con imagen real, carrusel interactivo 3x3 de tratamientos y servicios, bloques de Equipo y Clínica, banda de contacto.
- **Tratamientos (`/tratamientos-y-servicios`)**: Listado completo de los 9 servicios en disposición alterna texto-imagen.
- **Nosotros (`/el-equipo`)**: Fotografía grupal y cuadrículas de equipo médico y equipo de administración.
- **Contacto (`/contacto`)**: Formulario interactivo, mapa y datos directos de contacto (teléfono, correo y dirección).

## 🛠️ Desarrollo local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```

## 🌐 Despliegue en Vercel

1. Importa este repositorio en tu cuenta de [Vercel](https://vercel.com).
2. Framework Preset: **Next.js**.
3. Haz clic en **Deploy**.
